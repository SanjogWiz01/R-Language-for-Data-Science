# 1. What R Is

R is a programming language and environment designed for working with data, statistics, and graphics. You can use it to calculate, transform datasets, make visualizations, and build reproducible analyses.

R evaluates expressions. Type an expression and R returns a result:

```r
2 + 3
sqrt(16)
```

The first expression returns `5`; the second returns `4`. A script is a saved text file of R expressions that you can run again.

R is case-sensitive: `score`, `Score`, and `SCORE` are different names. Functions are called with parentheses, such as `mean(c(2, 4, 6))`.

For data science, R is one part of the work. You still need a clear question, suitable data, careful reasoning, and an honest explanation of uncertainty and limits.
