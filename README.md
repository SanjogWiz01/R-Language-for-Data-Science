# R for Data Science: Learning Hub

A beginner friendly path through R programming, probability, statistics, data visualization, and practical data science. Learn one idea, practice it with data, and keep your work in this repository.

## Start here

1. Open [START_HERE.md](START_HERE.md) and set up R and an editor.
2. Work through [your first R practice file](exercises/00_first_steps.R).
3. Read the lessons in [theory learn](theory%20learn/00-index.md) in order.
4. Run the code examples in [practice](practice/01_syntax_and_assignment.R).
5. Follow [ROADMAP.md](ROADMAP.md) at a pace that leaves time to practice.
6. Save short concept notes in `notes/` and finished analyses in `projects/`.

## Learning path

| Stage | What you will learn | Evidence of progress |
| --- | --- | --- |
| R foundations | Objects, functions, vectors, data frames, scripts | Small scripts you can explain |
| Data work | Import, clean, transform, and summarize data | A tidy, documented dataset |
| Probability and statistics | Chance, sampling, uncertainty, inference | A written analysis with a justified conclusion |
| Visualization and communication | Clear plots and data stories | A report that answers a real question |
| Modeling | Regression, evaluation, and machine learning basics | A model compared with a simple baseline |
| Independent project | A complete, reproducible analysis | A project another person can follow |

## Suggested repository layout

```text
practice/    runnable R code examples for core language topics
exercises/   short practice scripts
notes/       your explanations, formulas, and questions
projects/    complete analyses with data sources and conclusions
```

## How to use this repository

- Practice regularly; short, repeated sessions work well.
- Type and adapt examples instead of only reading them.
- Keep a script for each exercise so you can rerun it later.
- Explain results in plain language and include uncertainty where it matters.
- Record where project data came from and what you changed.

No prior programming experience is required. Basic arithmetic is enough to begin; the roadmap introduces the math as you need it.
