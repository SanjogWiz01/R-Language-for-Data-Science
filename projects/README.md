# Projects

Put each complete analysis in its own folder. A useful project includes:

1. A short README with the question, data source, and how to rerun the analysis.
2. An R script or report that performs the analysis from start to finish.
3. Figures and a plain-language summary of the findings.
4. Limitations, assumptions, and questions for future work.

Use data you are allowed to share. Keep private or sensitive data out of this repository.
